What we built

An end-to-end pipeline
for Tamil language analysis

This project implements a full-stack semantic analyzer for the Tamil language — one of the world's oldest classical languages — using the ANTLR4 parser generator framework.

Starting from raw Tamil text, the system tokenizes input via a hand-crafted lexer, constructs a concrete syntax tree through a formal grammar, and performs semantic validation by enforcing subject–verb agreement rules rooted in Tamil grammar.

A key challenge was encoding Tamil's agglutinative morphology into formal grammar rules — the same verb stem carries different suffixes depending on the gender, number, and person of the subject. We mapped these rules exhaustively into ANTLR4 grammar actions.

The project ships with a Swing-based GUI parse tree viewer with multi-tab navigation, zoom controls, and per-sentence analysis — all running off a single Java executable.

Architecture Flow
1 Input Sentence (Tamil UTF-8 text)
2 Lexer — Tokenization via TamilLexer.g4
3 Parser — Grammar rules in Tamil.g4
4 Parse Tree Construction (ANTLR4 runtime)
5 Semantic Validator — Agreement checker
6 Output — VALID / INVALID + explanation
7 Swing GUI — Interactive parse tree viewer

Parser Grammar — Tamil.g4

// Top-level rule
file
    : sentence EOF
    ;

sentence
    : QUESTION_WORD? clause
      (LINK_WORD clause)*
      (PUNCT | QUESTION_MARK)?
    ;

// Clause with subject → validates agreement
clause
    : subject object* adverb* verbPhrase
      {
        checkAgreement(
          $subject.textVal,
          $verbPhrase.verbVal,
          $ctx.getParent().getText()
        );
      }
    | object* adverb* verbPhrase
    ;

subject returns [String textVal]
    : ADJ* PRONOUN    { $textVal = $PRONOUN.getText(); }
    | ADJ* TAMIL_WORD { $textVal = $TAMIL_WORD.getText(); }
    ;

Semantic Checker — Java Action

void checkAgreement(
    String subj, String verb, String sent) {

  if (verb == null) {
    semanticError(sent, "No verb found.");
    return;
  }

  // நான் → verb must end ேன்
  if (isFirstPerson(subj)) {
    if (!isFirstPersonVerb(verb))
      semanticError(sent,
        "'நான்' needs verb ending 'ேன்'");
    return;
  }

  // அவர்கள் → plural verb (ார்கள் / ினர்)
  if (isPluralPronoun(subj)) {
    if (!isPluralVerb(verb))
      semanticError(sent,
        "Plural subject needs plural verb.");
    return;
  }

  // Noun gender → ending ன் / ள் maps to ான் / ாள்
  if (isMaleNoun(subj) && !isMaleVerb(verb))
    semanticError(sent, "Masculine noun → 'ான்'");
}

Lexer Rules — Key Tokens

// Pronouns
PRONOUN
    : 'நான்'     // I (1st person)
    | 'நாங்கள்' // We (plural)
    | 'அவன்'    // He (male)
    | 'அவள்'    // She (female)
    | 'அவர்கள்' // They (plural)
    ;

// Tense + Agreement suffixes
TENSE_SUFFIX
    : 'வந்தேன்'    // came (I)
    | 'வந்தான்'    // came (he)
    | 'வந்தாள்'    // came (she)
    | 'வந்தார்கள்' // came (they)
    | 'சென்றோம்'   // went (we)
    // …28 total verb forms
    ;

// General Tamil word fragment
TAMIL_WORD
    : (TAMIL_CLUSTER)+
    ;

fragment TAMIL_BASE
    : [\u0B85-\u0BB9]
    ;

Core logic

Subject–Verb Agreement
Rules Implemented

Subject Person / Gender Rule Valid Verb Ending Example Violation
நான் 1st person singular (I) isFirstPersonVerb(v) —ேன் நான் வந்தான் ❌
நாங்கள் 1st person plural (We) isFirstPersonPluralVerb(v) —ோம் நாங்கள் வந்தேன் ❌
அவர்கள் 3rd person plural (They) isPluralVerb(v) —ார்கள் / —ினர் அவர்கள் வந்தான் ❌
அவன் 3rd person male (He) isMaleVerb(v) —ான் அவன் வந்தார்கள் ❌
அவள் 3rd person female (She) isFemaleVerb(v) —ாள் அவள் வந்தான் ❌
Noun ends ன் Masculine noun (e.g. ராஜன்) isMaleNoun(s) → isMaleVerb(v) —ான் ராஜன் வந்தாள் ❌
Noun ends ள் Feminine noun (e.g. கமலா) isFemaleNoun(s) → isFemaleVerb(v) —ாள் கமலா வந்தான் ❌
Neutral noun Common / proper nouns, places No pronoun match → no violation —ார் (honorific) ராஜா படித்தார் ✓
